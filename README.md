# CreoMaker 1.2

Запустите `start.cmd`. Рабочий экран откроется на `http://127.0.0.1:4191/`. Node.js, FFmpeg, FFprobe и встроенная библиотека хвостов и музыки находятся в этой папке.

## Интерфейс

Окно устроено как монтажная программа. Слева панель разделов: **Монтаж** (Ctrl+1), **Медиатека** (Ctrl+2) и **Экспорт** (Ctrl+3). В разделе «Монтаж» три панели: файлы, просмотр с таймлайном и инспектор с параметрами экспорта; кнопка запуска закреплена внизу инспектора. Переключатель «Подготовка / Варианты» находится в заголовке окна. Строка состояния внизу показывает FFmpeg, ход текущей обработки и папку вывода. По умолчанию включена тёмная тема, светлая переключается кнопкой в заголовке.

## Обработка

- **Clean3** обрезает и меняет формат кадра, накладывает зоны размытия, музыку и хвосты. Ползунок задаёт длительность хвостов от 30 секунд до 30 минут с шагом в секунду.
- **Уникализация** создаёт варианты видео и изображений с выбранными эффектами.
- **Изменения и проверка** управляет обрезкой краёв, уровнем и спектром звука, частотой кадров и формированием отчёта. В автоматическом режиме видео с частотой около 30 кадр/с получает 25 кадр/с. Для остальных входов используется 30 кадр/с. Можно указать 12–60 кадр/с вручную.
- **Метаданные и регион** содержит ручные поля и локальный генератор английских тегов. В новых MP4 при включённой перезаписи добавляются дата и идентификатор обработки. Авторство и права заполняются заданными вами значениями.

В карточке результата раскрывается сравнение с исходником. SHA-256 считается по всему файлу. Видео проверяется по четырём декодированным кадрам, звук — по четырём фрагментам до 0,4 секунды на частоте 44,1 кГц. JSON содержит отпечатки выборок, спектральные полосы, RMS и пик, частоту кадров, пространственные признаки и изменённые ключи метаданных. Для хвостов добавляется измеренная длительность вставки. Совпадения и недостаток измерений помечаются в отчёте.

## Библиотека

Музыка загружается из assets/music, видеохвосты из assets/Tails. Новые файлы появляются после возврата в окно CreoMaker или по кнопке «Обновить».

## Хранение

Медиа, задачи и результаты находятся в `data/creomaker`. В новых папках результата сохраняются только готовые медиафайлы. История задач и отчёты JSON хранятся в `data/creomaker/jobs`, а отчёты доступны для скачивания из карточки результата. Параметры интерфейса хранятся в IndexedDB на адресе приложения. Для переноса всей библиотеки и истории сохраните `data/creomaker` вместе с проектом.

Локальные проверки движка запускаются командой `tools\node.exe --test tests/creo-verification.test.cjs tests/creo-workflow.test.cjs`. Браузерный тест использует Playwright как инструмент разработки и временные данные.
